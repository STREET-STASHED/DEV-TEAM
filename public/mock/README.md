# Mock Images Directory

This directory contains placeholder images for development and testing purposes.

## Image Naming Convention

- `hoodie-1.jpg`, `hoodie-2.jpg`, `hoodie-3.jpg` - Hoodie product images
- `denim-jacket-1.jpg`, `denim-jacket-2.jpg` - Denim jacket images
- `leggings-1.jpg`, `leggings-2.jpg` - Athletic leggings images
- `sneakers-1.jpg`, `sneakers-2.jpg` - Sneaker images
- `boots-1.jpg`, `boots-2.jpg` - Boot images
- `necklace-1.jpg`, `necklace-2.jpg` - Jewelry images
- `ring-1.jpg`, `ring-2.jpg` - Ring images
- `default-product.jpg` - Fallback product image

## Note

For production, replace these placeholder images with actual product photos.
The current images are using the same placeholder to avoid external dependencies.
